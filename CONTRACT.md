## Tidy table (pandas DataFrame) produced by clean.py, consumed by quality/aqi/analytics
Columns: `row_id` (str "R<n>", n = 1-based index of the data row in the original table after the header),
`station` (canonical str), `ward` (str|None), `ts` (datetime64[ns], tz-naive local time; NaT if unparseable),
`pollutant` (one of POLLUTANTS), `value_raw` (str|None), `unit_raw` (str|None), `value_std` (float, NaN if unusable),
`flags` (list[str] of core.models.FLAGS). Optional: `lat`, `lon`.
Standard unit: µg/m³ for all pollutants, mg/m³ for CO (see STD_UNIT). `value_std` is NaN whenever a reading is unusable.

## core/aqi.py   (owner: AQI agent)
- `BREAKPOINTS`: dict pollutant -> list of (conc_lo, conc_hi, aqi_lo, aqi_hi) per CPCB table (PLAN.md section 3). Pb omitted.
- `subindex(pollutant: str, conc: float) -> float | None`  linear interpolation, ints inclusive at boundaries, > top bracket capped at 500, None if invalid.
- `category(aqi: float) -> str` (CATEGORIES), `category_color(cat: str) -> str` (hex), `category_emoji(cat) -> str`.
- `WHO_24H = {"PM2.5":15,"PM10":45,"NO2":25,"SO2":40,"O3":100,"CO":4}` (CO mg/m3, 24h) and `who_multiple(pollutant, conc) -> float | None`.
- `pollutant_averages(tidy: DataFrame) -> DataFrame`  columns station, ward, date (YYYY-MM-DD str), pollutant, avg (24h mean for all; for O3 and CO the max rolling 8-hour mean within the day), n_hours (distinct hours with valid data), valid (n_hours >= 16).
- `daily_aqi(tidy: DataFrame) -> DataFrame`  columns station, ward, date, aqi (float|NaN), category, dominant, n_pollutants, subindices (dict), valid (bool; needs >=3 valid pollutants incl. PM2.5 or PM10), reason (str, why invalid else "").
- Tests in tests/test_aqi.py: every breakpoint boundary for each pollutant, category edges, the 3-pollutant/PM rule, 16-hour rule.

## core/ingest.py, core/clean.py, core/quality.py   (owner: ingest agent)
- `ingest.read_input(text: str | None = None, file_bytes: bytes | None = None, filename: str | None = None) -> RawTable` where `RawTable` is a dataclass(df: DataFrame of str with column `_src_row` (int, 1-based data row), source_name: str, notes: list[str]). Detect delimiter (comma, tab, semicolon, pipe, whitespace-aligned), CSV/TSV/XLSX (first sheet with data), strip BOM, skip title/subtitle rows above the true header, drop fully blank rows, repeated header rows inside the data. Raise `ValueError` with a friendly message for empty / unusable input.
- `ingest.heuristic_mapping(raw: RawTable) -> ColumnMapping` rule-based fallback (source="heuristic"): recognise station/ward/timestamp/date/time columns by name, pollutant columns by name (PM2.5, pm25, PM 2.5, PM10, NO2, SO2, O3, ozone, CO, NH3) with units in header like "PM2.5 (ug/m3)", "NO2_ppb", long layout when columns like parameter/pollutant + value + unit exist.
- `clean.apply_mapping(raw: RawTable, mapping: ColumnMapping) -> tuple[DataFrame, list[str]]` returns the tidy table and a cleaning log. Handles: sentinels (NA, N/A, --, -, null, nd, bdl, -999, 9999 etc plus mapping.sentinel_tokens), decimal comma / thousands separators, units inside cells ("85 µg/m3"), "<5"/">500" (CENSORED), unit conversion to standard (ppb->µg/m³ at 25C: NO2 x1.88, O3 x1.96, SO2 x2.62, NH3 x0.70; CO ppm->mg/m³ x1.146; mg/m3->µg/m3 x1000 for non-CO; µg/m3->mg/m3 /1000 for CO), missing unit => assume standard + flag UNIT_AMBIGUOUS, ppb on PM => UNIT_MISMATCH and NaN, mixed date formats and DD/MM vs MM/DD (infer from data: any day>12 decides; else assume DD/MM), 12h/24h, canonicalise station and ward names ("Ward 12","ward-12","W12" -> "Ward 12"; trim, title-case, fix obvious typos via normalised matching), wide->long melt, row_id = "R<_src_row>", NEGATIVE/OUT_OF_RANGE (PM2.5>1500, PM10>2500, NO2>2000, SO2>2000, O3>1000, CO>100, NH3>5000 => NaN + flag), DUPLICATE exact repeats. Never crash on bad cells.
- `quality.flag_readings(tidy: DataFrame) -> DataFrame` adds STUCK (>=6 identical consecutive per station+pollutant), SPIKE (value > max(5 x rolling median of the previous 6 valid readings, median+150 for PM)), and recomputes nothing else; keeps existing flags.
- `quality.station_reliability(tidy: DataFrame) -> list[StationReliability]` coverage = valid readings / expected (hourly over the station's observed time span, per pollutant present), flagged_share, reliability = coverage*(1-flagged_share), label: >=0.75 reliable, 0.5-0.75 use with caution, else unreliable; include notes.
- `quality.quality_summary(raw: RawTable, tidy: DataFrame, cleaning_log: list[str]) -> QualitySummary` includes flag_counts, stations, gaps (plain statements like "Station X has no readings between 02:00 and 09:00 on 2026-11-03", missing pollutants, partial days), cleaning_log.
- tests/test_clean.py using small inline messy tables.

## core/analytics.py, core/diff.py, core/store.py, core/verify.py   (owner: analytics agent)
Use `core.aqi.daily_aqi` (assume the signatures above; code against them, a stub may be needed until it lands).
- `analytics.build_brief(tidy: DataFrame, quality: QualitySummary, area: str, source_name: str, source_hash: str) -> Brief`: fills station_aqi (latest valid day AQI, subindices, mean_aqi_period, trend_per_day via linear fit over valid days, reliability and confidence from quality.stations: reliable->high, use with caution->medium, else low) and findings. Findings (IDs F1.. in rank order): hotspot (top stations by latest AQI; an unreliable station can never be "high" confidence and gets a caveat), exceedance (stations/pollutants above WHO 24h guideline with multiples, `who_multiple`), trend (period slope per station, up/down/stable with thresholds), pattern (hour-of-day peak windows over the whole period; pollutant signature hints worded "consistent with"), gap (each significant data gap / unreliable station from quality), anomaly (stuck sensors, spike clusters, co-located disagreement). Each Finding: all citable numbers in `facts`, `formula` in plain words, `evidence_row_ids` (<=50 row_ids from tidy), `stations`, `confidence`, `caveats`.
- `diff.diff_briefs(current: Brief, previous: Brief | None) -> DiffResult` (has_previous=False when previous is None, with a helpful summary_facts). Fill station_changes (direction worse/better by delta threshold 10 AQI, same/new/dropped), category_transitions, new/resolved hotspots (top-3 membership), quality_changes (reliability labels changed, gap counts), new_finding_titles, summary_facts (e.g. n_worse, n_better, mean_delta, worst_station, ...).
- `store.py`: `save_brief(brief, directory=".briefs")`, `load_latest(directory=".briefs", exclude_id=None) -> Brief | None`, `list_briefs(directory) -> list[Brief]`. JSON files named by created_at. Robust to corrupt files.
- `verify.py`: `check_text(text: str, findings: list[Finding], extra_facts: dict | None = None) -> list[Issue]` with dataclass Issue(sentence, kind in {"unknown_citation","uncited_claim","unsupported_number"}, detail). Citation ids like [F3]. A number in the text is supported if it appears (within rounding tolerance 0.5% or abs 0.5) in any finding.facts value or extra_facts, or is a trivially safe number (years/dates, 1-5, 24, 8, 16, percentages derived are NOT safe). Be lenient on ordinals and dates. `check_object(obj, findings, extra_facts=None) -> list[Issue]` walks any pydantic model's string fields (and `cites` lists) and applies check_text.
- tests/test_analytics.py, tests/test_diff.py, tests/test_verify.py with small synthetic tidy tables (build them inline in the tests).

## llm/*   (owner: LLM agent)
Files: llm/client.py, llm/stages.py, llm/fallback.py, llm/prompts/*.md (one per stage), llm/demo_cache.py.
- `client.py`: `MODELS = ["gemini-3.8-flash", "gemini-3.6-flash", "gemini-3.5-flash-lite"]` single constant (env override `GEMINI_MODEL`), key from env `GEMINI_API_KEY` (or `GOOGLE_API_KEY`). `generate_json(prompt: str, system: str, schema: type[BaseModel], temperature=0.2) -> BaseModel` using google-genai `client.models.generate_content` with `config=GenerateContentConfig(response_mime_type="application/json", response_json_schema=schema.model_json_schema(), system_instruction=system, temperature=...)`, validates with `schema.model_validate_json`, retries with backoff, walks MODELS on 404/429/503, raises `LLMUnavailable` when no key or all fail. `llm_available() -> bool`.
- `stages.py` (each wraps try/except LLMUnavailable/validation errors and returns the deterministic fallback with `used_fallback=True`; never raises):
  - `map_columns(raw: RawTable) -> ColumnMapping | None` (P1: header + first 30 rows; returns None on failure so caller uses `ingest.heuristic_mapping`; validate that every referenced column exists and pollutant names are canonical, drop invalid entries, set source="llm").
  - `interpret(brief: Brief, diff: DiffResult) -> Interpretation` (P2)
  - `plan_actions(brief: Brief, diff: DiffResult, persona: str) -> ActionPlan` (P3; loads data/action_library.yaml, passes only items relevant to the persona; drops actions citing unknown finding IDs; renumbers ranks)
  - `write_internal_note(brief: Brief, diff: DiffResult, interp: Interpretation, plan: ActionPlan) -> InternalNote` (P4)
  - `write_advisory(brief: Brief, language: str, reading_level: str, area_label: str) -> Advisory` (P5; ONE call per language x level; languages: "English","Hindi","Marathi","Kannada","Tamil","Bengali","Telugu","Gujarati")
  - `verify_draft(text: str, brief: Brief) -> list[VerifyIssue]` (P6, optional Gemini pass; returns [] on failure)
  Prompts receive the Brief/Diff as compact JSON (`FINDINGS`, `QUALITY`, `DIFF`) and obey the grounding contract in PLAN.md section 5 (use only facts in FINDINGS, cite [F#], hedge causes with "consistent with", say `insufficient evidence` rather than guess, never medical diagnosis, advisory care text tied to the CPCB category).
- `fallback.py`: pure-Python template versions of every stage output (interpretation from findings, plan from the library ranked by trigger match, internal note, advisory in English + Hindi templates keyed by AQI category with care blocks for children/older adults/sensitive groups, other languages fall back to English plus a note). The fallbacks must be good enough to demo with no API key.
- `demo_cache.py`: `save_run(key, obj)`, `load_run(key)` JSON cache under `.demo_cache/` so a saved Gemini run can be replayed offline; `stages.py` consults it when the API is unavailable (key = hash of stage + input).
- tests/test_llm_fallback.py (no network): every stage returns valid schema objects offline; client raises/handles missing key.

Generate with a deterministic Python script `scripts/make_sample_data.py` (seeded) and commit the script AND outputs. The data must produce AQI categories ranging Moderately Polluted..Very Poor with a believable evening peak.
